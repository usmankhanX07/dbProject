# dbProject
Databases Project based on a Airport mini-world.
We'll be preparing our end of semester project here for the Databases course. Initially we were planning to construct and finalize our database using Oracle SQL Developer as taught in our labs, but we will be taking a different approach using .php scripts along with mySQL queries with HTML/javaScript tied to the front-end. I will be documenting my journey here as well as keep commits for future reference. We are logging in as localhost from the xampp server-wide stack and the Apache WebService.
